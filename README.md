# Sistedes2026

Web estatica del programa SISTEDES 2026 publicada con GitHub Pages.

## Archivos principales

- `index.html`: pagina principal del programa.
- `style.css`: estilos de la pagina.
- `data/programa-config.json`: configuracion general del horario.
- `data/tracks/*.json`: datos detallados de cada track.

## Publicacion

La rama `main` se publica desde la raiz del repositorio mediante GitHub Pages:

```text
https://marinamacia.github.io/Sistedes2026/
```
